# Dynamic Proxy

> **Autogenerated from:** `references/java-design-patterns/dynamic-proxy`

## When to Use
- When you need to decouple dynamic proxy implementation from client code
- When the dynamic proxy logic varies independently from the rest of the system
- When you want to enforce a consistent dynamic proxy interface across implementations
- When the dynamic proxy behavior needs to be configured or swapped at runtime
- When standardizing dynamic proxy handling across a team or codebase

## Common Mistakes

```java
// WRONG: Using Proxy.newProxyInstance without interface type check
// Creates a proxy but doesn't verify the target actually implements the interface.
public <T> T createProxy(Object target, Class<T> intf) {
    return (T) Proxy.newProxyInstance(
        intf.getClassLoader(),
        new Class<?>[]{intf},
        (proxy, method, args) -> {
            System.out.println("Calling " + method.getName());
            return method.invoke(target, args);
        }
    );
    // ClassCastException at runtime if target doesn't implement intf
}

// CORRECT: Validate interface before creating proxy
// Check that the target implements the requested interface.
public <T> T createProxy(Object target, Class<T> intf) {
    if (!intf.isInstance(target)) {
        throw new IllegalArgumentException(
            "Target must implement " + intf.getName());
    }
    return (T) Proxy.newProxyInstance(
        intf.getClassLoader(),
        new Class<?>[]{intf},
        (proxy, method, args) -> {
            long start = System.nanoTime();
            try {
                return method.invoke(target, args);
            } finally {
                long elapsed = System.nanoTime() - start;
                System.out.printf("%s took %dns%n", method.getName(), elapsed);
            }
        }
    );
}
```

```java
// WRONG: Proxy method handler that's not thread-safe
// Shared mutable state in InvocationHandler without synchronization.
public class UnsafeHandler implements InvocationHandler {
    private int callCount = 0;  // shared, mutable, unsynchronized

    @Override
    public Object invoke(Object proxy, Method method, Object[] args) {
        callCount++;
        // ...
    }
}

// CORRECT: Thread-safe handler with AtomicInteger or synchronized block
public class SafeHandler implements InvocationHandler {
    private final AtomicInteger callCount = new AtomicInteger(0);

    @Override
    public Object invoke(Object proxy, Method method, Object[] args) {
        callCount.incrementAndGet();
        return method.invoke(target, args);
    }
}
```

## Gotchas
- Proxy only works with interfaces — you cannot proxy concrete classes with `java.lang.reflect.Proxy`.
- For class-based proxying, use CGLIB or ByteBuddy instead.
- `equals()`, `hashCode()`, and `toString()` calls on the proxy get intercepted too — handle them carefully.
- Recursive proxy calls (the handler invoking methods on itself) cause stack overflow.
